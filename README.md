# eye-care

Jyoti Eye Care - Advanced Cataract & Oculoplasty Center (Nagpur)
Led by Dr. Ruchita Sontakke (MBBS IGGMC, MS Ophthalmology MAMC New Delhi, DNB, Ex-SR MAMC).

## Built With
- **Next.js 15 (App Router)**
- **React 19 & TypeScript**
- **Tailwind CSS**
- **Lucide React**

## Getting Started

Run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
